# NOVA MOD MENU

A blue/cyan interface prototype targeting GTA V PS3 1.10.

## Current status
This repository contains a browser-based UI prototype only. It is **not** a working PS3 SPRX/plugin and does not modify GTA V.

## Preview
Open `index.html` in a browser.

## Planned categories
- Player: Fly Mode, Noclip, speed presets
- Characters
- Vehicles
- Teleport
- File Manager
- Settings

## Controls concept
- Open: Konami sequence
- Close: Circle
- Move: Left stick
- Rise: R2
- Descend: L2

Actual in-game support requires a verified PS3 1.10-compatible plugin approach and testing. No game files are included. Keep original GTA V files backed up and untouched.
